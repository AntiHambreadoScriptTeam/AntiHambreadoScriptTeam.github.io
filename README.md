## Qué es

Anti-Hambreado Script Team es un repositorio de scripts de Roblox. Publicamos los enlaces directos, sin acortadores y sin pasos intermedios.

La página reúne los scripts, las actualizaciones y los recursos del equipo en un solo lugar.

## 📜 Scripts

<div id="scripts"></div>

Biblioteca de scripts organizada por juegos. Incluye hubs y scripts individuales con funciones como:

- 🎯 Aimbot
- 👁️ ESP
- 🗡️ Kill Aura
- 🏃 Auto Win
- 💨 Modificaciones de velocidad
- 🧱 Noclip
- ♾️ Stamina infinita

El contenido se actualiza según las actualizaciones de Roblox.

**Catálogo completo:** https://antihambreadoscriptteam.github.io/scripts

> [!IMPORTANT]
> Los scripts se prueban antes de publicarse. Si uno deja de funcionar, se actualiza o se retira.

## 🛠️ Executores
